# 📊 Crypto Dashboard

Интерактивный дашборд для отслеживания криптовалют.

## 🚀 Функционал

- Карточки с актуальными курсами монет
- График цены Bitcoin за 7 дней
- Таблица с топ-10 криптовалютами
- Поддержка тёмной темы
- Анимации и современный UI

## 🛠 Технологии

- React + TypeScript
- TailwindCSS
- Recharts
- Axios
- Framer Motion

## 📦 Установка

```bash
git clone https://github.com/username/crypto-dashboard.git
cd crypto-dashboard
npm install
npm run dev
```
